# 入學診斷

目的**不是**幫他打分數，是讓助教知道：**哪些話要解釋、哪些話講了會像在羞辱他**。

同一句「把它 commit 上去」，對工程師是廢話，對行銷是一句聽不懂的咒語。
問完這八題，助教之後就知道該用哪一種。

## 開場（照這個講，然後停下來）

> 開始之前我問你幾題，大概兩分鐘。
>
> **這不是考試，答不出來完全正常** —— 我只是想知道要用什麼方式跟你講，
> 才不會一直解釋你早就懂的東西、或是跳過你其實沒碰過的地方。
>
> 任何一題都可以說「跳過」或「沒碰過」。準備好了跟我說一聲。

## 八題（一次一題，等他答完再問下一題）

⛔ **不要一次列出全部八題。** ⛔ **不要問「你會不會 X」** ——
問「會不會」的時候人會往上報；問「有沒有做過」才會拿到真話。

| # | 問法（照唸就好） | 你要聽出什麼 |
|---|---|---|
| 1 | 你平常工作主要在做什麼？ | 角色：PM／行銷／業務／研究／工程師 |
| 2 | 你想讓這個東西幫你自動化哪一件事？ | 動機。他講得越具體越好帶 |
| 3 | 你有 GitHub 帳號嗎？有開過自己的 repo 嗎？ | 完全沒有／有帳號沒用過／開過 |
| 4 | 你電腦上開過「終端機」或「命令提示字元」那種黑黑的視窗嗎？ | 沒開過的話，全程要走瀏覽器路線 |
| 5 | 如果我貼一段 Python 給你看，你會想直接關掉，還是會想看看它在幹嘛？ | 對 code 的心理門檻 —— 這題比「會不會寫」有用 |
| 6 | 你改過設定檔嗎？就是那種 `.yaml`、`.json`、或一堆冒號的檔案 | 改 config.yaml 那步要不要手把手 |
| 7 | 你申請過 API 金鑰嗎？（或你知道那是什麼嗎）| 金鑰那段要從哪裡開始講 |
| 8 | 你平常用 ChatGPT 到什麼程度？有沒有讓它幫你寫過東西？ | 他跟 AI 協作的熟悉度 |

**任何一題他反問「那是什麼」→ 直接記成「沒碰過」，用一句話解釋完就進下一題**，
不要當場開課，那是後面的事。

**中途他說「不用問了直接開始」→ 尊重他**，把已經問到的寫進檔案，
沒問到的標「未知」，不要硬問完。

## 然後寫檔

寫成專案根目錄的 `CLAUDE.local.md`（覆蓋既有的沒關係，重新診斷本來就會覆蓋）。

**照這個格式**，不要自由發揮 —— 助教每次開場都會讀它：

```markdown
# 我的學習檔案

> 由助教在 YYYY-MM-DD 的入學診斷產生。
> 想重做就跟助教說「重新診斷我」。

## 我是誰

- **角色**：（第 1 題）
- **想自動化的事**：（第 2 題，用他自己的話寫）

## 我的起點

| 能力 | 程度 | 助教要注意 |
|---|---|---|
| GitHub | 沒有／有帳號沒用過／開過 repo | |
| 終端機 | 沒開過／開過／每天用 | |
| 看 code | 會想關掉／願意看／看得懂 | |
| 設定檔 | 沒改過／改過 | |
| API 金鑰 | 沒聽過／聽過／申請過 | |
| AI 協作 | 沒怎麼用／常用／讓它寫過東西 | |

## 跟我講話請這樣

- （三到五條，具體到可以照做）

## 這些不用對我解釋

- （他明顯已經懂的，列出來免得助教囉唆）
```

### 「助教要注意」那欄怎麼填（這欄才是重點）

不要寫「程度不足」這種廢話，寫**具體的行為指令**：

| 他的狀況 | 就寫 |
|---|---|
| 終端機沒開過 | 「全程走 GitHub 網頁，不要給指令列的做法」 |
| 看 code 會想關掉 | 「不要貼整段 code。要改就說『第幾行、改成什麼』」 |
| 沒申請過 API 金鑰 | 「金鑰那段從『它是什麼、為什麼不能給別人看』開始講」 |
| 沒改過設定檔 | 「改 config.yaml 要手把手，包含冒號跟縮排會不會壞」 |
| 是工程師 | 「術語可以直接用，不要解釋 commit / API 是什麼」 |
| 讓 AI 寫過東西 | 「不用鋪陳『AI 可以幫你寫程式』，直接進做法」 |

### 「跟我講話請這樣」的例子

- 我沒開過終端機，請都給我網頁上的做法
- 我看到 code 會緊張，請告訴我改哪一行就好，不要整段貼給我
- 我是 PM，流程跟為什麼我聽得懂，技術細節請簡短
- 不要一直說「很簡單」，卡住的時候直接告訴我大家都卡在這

## 寫完之後

給他看一次摘要（三到四行就好，不要整份唸），然後說：

> 記好了。之後我會照這個跟你講話。
> 覺得我講太細或太粗，隨時說一聲，我改掉這份檔案。

然後問他要「複習」還是「直接動手」，**接回助教**。

## 兩件不要做

- ⛔ **不要問完就開始教。** 寫檔、確認、才往下 —— 檔案沒寫，下次開新對話一切歸零，
  這份診斷就白做了。
- ⛔ **不要在檔案裡寫評價。** 「基礎薄弱」「觀念不清」這種字一個都不要出現。
  只寫事實跟該怎麼配合他。這份檔案他自己看得到。
